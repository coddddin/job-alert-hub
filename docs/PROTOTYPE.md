# 로컬 프로토타입 v0.1

## 범위

가상 공고 12건으로 검색·스크랩·지원 상태·알림 설정을 확인하는 첫 버전이다. 실제 수집, Google 로그인, DB, 메신저·이메일 발송은 수행하지 않는다.

현재 Node.js 내장 HTTP 서버와 브라우저 ES 모듈을 사용한다. 외부 설치 없이 검증 가능하도록 선택했다. `lib/matching.js`는 UI와 분리되어 이후 Next.js/TypeScript 전환 시 활용할 수 있다.

## 파일 구조

- `public/`: 화면, 스타일, UI 이벤트
- `data/jobs.js`: 개인정보가 없는 가상 공고
- `lib/matching.js`: 직무·근무지·경력·키워드 판정
- `lib/state.js`: 브라우저 저장 데이터 검증
- `server.mjs`: 허용된 정적 파일만 제공하는 로컬 서버
- `test/`: Node.js 내장 테스트

## 동작

기본 목록은 서울 신입 개발자 6건, 확인 필요 1건이다. 기본 알림 미리보기는 경력무관을 제외한 5건이다. 경력 필수, 사업개발, 교육 광고를 제외한다. 공고별 경력은 샘플에 미리 정규화되어 있으며 본문 자동 해석은 구현하지 않았다.

목록 필터와 알림 규칙은 독립 객체다. 목록은 변경 즉시 저장하고 알림은 저장 버튼을 눌러 반영한다. 설정·스크랩·지원 상태는 localStorage에 저장한다. 저장소를 사용할 수 없으면 경고하고 현재 화면의 메모리에서 동작한다.

## 검증

- `node --test`: 필터 경계, 알림 제외, 복수 근무지, 키워드 AND, 부문별 경력, 설정 독립성, 저장 데이터 복원, 서버 파일 노출 제한 — 7개 통과.
- `node --check public/app.js`, `node --check server.mjs`: 문법 검사 통과.
- 브라우저: 기본 목록 6건/확인 필요 1건/알림 5건, 프론트엔드 목록 2건에도 알림 5건 유지, 스크랩 저장 및 새로고침 유지, 알림 화면 및 저장 안내 확인.
- 좁은 모바일 뷰포트에서 문서 가로 넘침 없음 확인. 실제 휴대폰 테스트는 미수행.

## 다음 단계

실데이터 API 자격 및 승인, 카카오 실기기 검증, 정식 프레임워크/DB 전환, 유사 공고·관심 없음·마감 변경 알림이 남아 있다. 모바일 반응형 CSS는 포함하지만 실기기 푸시와 PWA 설치는 구현하지 않았다.
