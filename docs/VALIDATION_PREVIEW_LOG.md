관측: 40건 중 HTTP 200 34건, 307 6건. 관측 원본은 `.scrapling-local/validation-40/`.

검토 결과:
- 전체 h2 대조 때문에 신형 레이아웃의 ‘접수기간’ 등 섹션 제목이 회사명 충돌로 오인됨(2건).
- dt/dd 마감 레이아웃에서 ‘채용 시 마감’이 빠지고 JSON-LD 날짜만 전달됨.
- ‘신입·경력’에 직무별 조건이 붙은 공고가 존재. 신입 모두 지원 가능으로 단정하면 안 됨.
- 기존 개발·신입 중심 추천 규칙을 그대로 적용하면 신규 공고가 대부분 숨겨짐.
  검증 미리보기는 직무 추천을 하지 않고 전체 공고부터 보여준다.
- 별도 도구만으로 끝내면 통합 목표·접근성이 부족하므로 출처 표시/필터와 쉬운 실행 진입점 필요.

보완·테스트 결과는 진행 중 다음 반복에 추가한다. 현재 숫자는 정확도 주장 아님.

## 사용자 요청에 따른 중간 저장

사용자가 ‘적당히하고 작업내용 저장’을 요청하여 구현을 여기서 중단한다.
추가 지시: 필요한 경우 검증 완료 PR의 main 병합 허용, 짧고 알기 쉬운 커밋/PR 제목.
이번 작업은 미완료 상태라 병합하지 않고 초안 PR로 보관한다.

저장한 코드:
- `batch_live.py`: 고유 상세 최대 50건 검증 및 요청별 결과 보존.
- `extract.py`: HTTP 상태를 호출자가 분류할 수 있는 `HttpStatusError` 추가.
- 웹 서버의 인스턴스별 미리보기 설정. 기본 운영 라우트/데이터는 유지.
- 미리보기 화면 초안: 검색·지역·경력·마감 포함 필터, 원문과 해석, 원본 공고 링크.
- `preview.mjs --snapshot PATH`: 기존 스냅샷을 읽는 localhost 미리보기 실행 명령.

저장 직전 확인: 기존 Python 14개 테스트 통과. 새 미리보기 JS 3개 파일 문법 검사 통과.
신규 배치/미리보기 전용 회귀 테스트, 브라우저 렌더링, 접근성, 혼합 출처 검증은 아직 하지 않았다.
확대 표본 전체 원문 대조도 아직 하지 않았으므로 34건의 정확도를 주장하지 않는다.

다음 시작점 (우선순위 순):
1. h2 전체 비교로 인한 회사명 false conflict 2건을 합성 fixture로 재현하고 헤더 범위를 제한한다.
2. dt/dd 마감일 레이아웃 및 포지션 카드의 경력 연차를 보존한다.
   50337141은 화면 `경력1년↑`인데 현재 결과는 `경력`이다.
   50340461은 `2026.12.10(목) 채용 시 마감`인데 현재 결과는 날짜만 남는다.
3. 50333015는 모집요강에 근무지 항목이 없었다. 기업 주소로 근무지를 추정하지 말고 미상 유지.
4. 신규 배치의 307 계속 진행/403·429 중지/부분 결과 보존과 미리보기 라우트 격리 테스트.
5. 통합 목표: 출처 표시·필터 및 기존 ALIO 스냅샷과 병합 미리보기. ALIO 실데이터는 아직 요청 안 함.
6. 접근성: 쉬운 실행 진입점, 경력 연차와 부문별 조건 경고, 키보드·모바일 브라우저 확인.
7. 독립 대조 라벨 작성, 정확도/누락 집계, 전체 CI 후 완료 여부 판단.

로컬 관측은 `.scrapling-local/validation-40/`의 `run.json`, `batch.json`,
`attempts.jsonl`, 필드별 참고 HTML에 보존되어 있다. 원문 자료는 git 제외로 원격 백업되지 않는다.
레이아웃 조사 파일 `.scrapling-local/*-inspection.txt`는 담당자 등 불필요 정보가 포함될 수 있어

## 2026-11-15 / 반복 2 완료

사용자의 계속 진행 지시에 따라 작업을 재개했다. 앞선 중간 저장 시도는 승인 검토 사용량
한도로 git commit 전에 중단되었으며, 실제 파일은 보존되어 있었다.

보완:
- 회사명은 공고 제목 앞의 헤더 h2만 대조하여 다른 섹션 제목의 오인을 제거.
- dt/dd 마감 구조와 ‘채용 시 마감’을 보존.
- PositionJobView 포지션 카드에서 연차 추출. 부문별 경력 값 충돌은 확인 대상으로 유지.
- 새 배치 테스트에서 redirect 제외 후 계속, 429/네트워크 오류 중지, 부분 결과 보존 확인.
- 기존 ALIO/웹 기본 동작을 변경하지 않는 서버별 미리보기 라우트 구성.
- 동일 기준일의 기존 스냅샷과 `--base`로 결합 가능. 중복 ID나 다른 기준일은 오류로 안내.
- 출처·검색·지역·경력·마감 필터, 원문/해석/연차 표시, 세부 조건 안내, 안전한 원본 링크.
- `미리보기 실행.cmd` 진입점 추가. 로컬 스냅샷이 없으면 안내하고 자동 수집하지 않는다.

검증:
- HTTP 200 34건의 별도 DOM 대조. 회사 34/34, 제목 34/34, 경력 34/34, 마감 34/34,
  근무지 31/31 일치. 근무지 1건은 원문 없음 확인, 2건은 근거 부족으로 미검토.
  검토한 존재 값은 수정 전 162/167 → 수정 후 167/167. 40건 전체의 성공률·정확도와 다르다.
  코드 작성 에이전트의 원문 대조이며 독립된 사람의 검수가 아니다. 같은 표본으로 수정/평가하여
  일반화할 수 없고 추가 holdout 검증이 필요하다.
- 50337141 포지션 카드는 11월 15일 재확인. 다른 33건은 11월 14일 보존한 최소 필드 자료 사용.
- Python 21개 테스트 통과. 웹 43개 테스트 통과 후 연차 표시 테스트 1개 추가.
- 실제 브라우저 34건 표시, ‘헬킨’ 검색 1건, 부산 필터 4건(미상 지역 2건 포함) 확인.
  Tab 키로 검색에서 지역 필터 이동. 좁은 화면에서 가로 넘침 없음(clientWidth=scrollWidth=375).
- 기존 ALIO와 혼합 출처 검증은 합성 스냅샷으로 수행. 실제 ALIO API는 호출하지 않았다.

최종 집계: `tools/public-jobs/validation-expanded-2026-11-15.json`.
개별 원문/라벨은 `.scrapling-local/reviewed-labels.json`, 보완 결과는
`.scrapling-local/validation-fixed/batch.json`, 화면용은 `.scrapling-local/preview/snapshot.json`.

미검증/제한: 다른 사이트·다중 근무지 실표본·장기 운영·전체 사이트 대표성·독립 검수,
