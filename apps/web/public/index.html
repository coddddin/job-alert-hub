      북마클릿

      잡코리아 화면에서 바로 판정하기

      잡코리아 검색 결과에 공고마다 맞춤 · 확인 필요 · 제외 배지를 붙입니다. 이 사이트와 같은 kr-job-parser가 경력·근무지·마감 표기를 해석해요.

      1. 아래 버튼을 브라우저 북마크바로 끌어다 놓으세요. 북마크바가 안 보이면 Ctrl/⌘+Shift+B.
      2. 필터 옆 잡코리아 바로가기로 이동하세요. 판정 조건(근무지·경력무관)은 잡코리아 주소에서 읽으므로, 잡코리아에서 필터를 바꿔도 따라갑니다.
      3. 북마크를 누르세요. 배지를 누르면 원문과 해석이 보이고, 해석이 틀렸으면 틀렸어요로 신고할 수 있어요. 한 번 더 누르면 꺼집니다.

      JAH 판정

      공고 내용을 어디로도 보내지 않아요. 신고한 표기(공고 번호와 표기 글자)만 그 브라우저에 남고, 패널의 내보내기를 누를 때만 파일이 됩니다. 신고 파일은 파서 정확도를 재는 정답 셋을 만드는 데 씁니다.
